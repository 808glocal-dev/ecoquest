## v8 마우스 조작
- 우주: 왼쪽 드래그로 시야 이동, 휠로 확대/축소, 행성 클릭으로 접근
- 행성 접근 화면: 드래그로 행성 주위를 돌며 관찰, 휠 확대/축소, **착륙하기** 버튼
- 지상: 짧게 왼쪽 클릭하면 캐릭터가 걸어감, **마우스 드래그는 3D 카메라를 회전**. 휠로 확대/축소.
- 오른쪽 드래그도 시점 조절 가능. 화면의 +/− 버튼도 있음.
- 키보드 WASD/방향키와 모바일 방향 버튼도 유지.

## 주의
