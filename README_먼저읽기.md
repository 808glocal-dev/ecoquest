# 뽀송별 — 고요한 우주와 긴 산책 (v3, 개발 검증용)

이 버전은 앞서 만든 독립 게임의 **느린 이동과 풍경 감상**을 강화한 실험 릴리스입니다.

## 바뀐 점
- 7개 행성(숲/바다/언덕/마을/과수원/이웃/밤)의 기존 절차적 지형을 유지합니다.
- 걷기 속도 약 1.95 게임 단위/초, 가속·감속 적용, 카메라 지연 추적, 느린 보폭 흔들림. Shift로 선택적 빠른 이동.
- 착륙 직후 카메라를 멀리 배치해 주변 풍경을 더 넓게 봅니다.
- 지형 스트리밍, 40개 원본 미션 ID, 인증 서버 연결 코드를 유지했습니다.
- 친구 공개는 옵트인이고 기존 회원·포인트 데이터를 삭제하지 않습니다.

## 실행
1. 프로젝트 폴더 구조를 유지한 채 테스트 브랜치에 올립니다.
2. Vercel Preview에서 `/game/`을 엽니다. 루트 `index.html`은 통합 게임으로 연결되므로 운영 main에 바로 올리지 마세요.
3. 우주에서 행성 선택 → 착륙 → WASD/방향키 산책, 휠 확대/축소, 마우스 드래그, 앉기/음악, 미션 장소 접근을 검사합니다.
4. `npm run check`로 절차적 지형/미션 매핑을 점검합니다.

## 아직 검증하지 못한 것
- 실제 GPU WebGL 시각 품질, 저사양 기기 프레임률 및 현장 모바일 체감
- 실제 AI 인증/서버 저장, 실제 2인 친구 만남, 상점·결제 등 기존 전체 기능
- 원본 에코퀘스트의 포인트 보상 정책을 이 게임에 안전하게 이전하는 작업

**운영 전환 파일이라고 주장하지 않습니다.** 예전 회원 기록은 그대로 사용하지만, 인증 서버의 환경 변수/보안 규칙/운영 검증이 필요합니다. 비밀키를 GitHub에 넣지 마세요.
