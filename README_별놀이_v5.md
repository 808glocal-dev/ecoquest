# 뽀송별 v5 — 직접 플레이하는 환경미션

이 버전의 🎮 별놀이는 **실제 사진 인증 없이 게임 세계 안에서 플레이하는 환경 퍼즐**입니다. 기존 AI 사진 인증 40종과 별개입니다.

## 시작
1. `game/`에 접속해 우주 여행을 시작합니다.
2. 행성에 착륙한 뒤, 화면 오른쪽의 🎮 **별놀이** 메뉴를 누릅니다.
3. 또는 착륙 지점 근처 초록빛 게임 표지판으로 걸어가 **환경놀이 시작**을 누릅니다.
4. 현재 행성의 게임을 선택해 플레이합니다.

## 실제 플레이 유형
- 🌲 초록숨별: 빈 땅에 토종 식물 선택하여 심고 물주기
- 🐚 물결퐁별: 바닷가 쓰레기를 올바른 수거함에 분류
- ☁️ 바람솜별: 에너지 소비에 맞춰 재생에너지 조합 맞추기
- 🏡 반짝집별: 생활 전력을 아끼면서 필요한 생활 기능 유지하기
- 🍎 소풍식탁별: 남은 음식·포장재를 맞는 장소에 정리
- 🌷 나눔마을별: 고장난 물건의 원인과 수리 방법 고르기
- 🌙 별빛산책별: 별빛 정원에 토종 식물 심고 돌보기

종류별로 실제 버튼·퍼즐·진행률·성공 조건이 작동합니다. 완료하면 게임 안의 '새싹빛'이 누적됩니다. 기기별 localStorage에 저장되며 기존 Firebase 포인트·CO₂·AI 인증 기록은 절대 갱신하지 않습니다. 미션 완료가 현실에서 실제 환경효과가 발생했다는 뜻은 아닙니다.

## 배포 주의
`index.html`은 루트에서 게임을 여는 기존 테스트 진입점이고, 실제 게임 파일은 `game/` 아래에 있습니다. 기존 운영 사이트 `main`을 덮어쓰지 말고 미리보기 브랜치에서 테스트하세요. Firestore 기존 권한 오류는 이 게임 모듈과 별도로 해결해야 합니다.
