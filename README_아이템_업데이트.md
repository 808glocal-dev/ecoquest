# 뽀송별 v4 — 산책·수집·환경미션·쉼터 꾸미기

## 실행
압축을 풀고 **폴더 구조를 그대로 유지**한 다음 웹 서버에서 `/game/`을 엽니다. 단일 HTML 파일을 파일 탐색기에서 직접 여는 방식은 모듈 및 Firebase 연결 문제로 지원하지 않습니다.

GitHub의 운영 `main`을 바로 교체하지 말고 테스트 브랜치에서 Vercel 미리보기를 확인하세요. 이 압축에는 `index.html`이 포함되어 있으며 **운영 사이트의 index.html에 바로 덮어쓰면 기존 화면을 교체합니다.** 테스트 브랜치에서만 사용하세요.

## 새로 구현
- 7개 행성에서 구역마다 다른 반짝이는 수집물 생성. 수집 장소에 가까이 접근해 '✨ 줍기' 클릭
- 수집한 재료는 🎒 가방에 보관
- 재료 조합으로 돗자리, 화분, 의자, 조명 제작
- 🪴 꾸미기에서 소품을 최대 6개 골라 착륙 지점 근처 3D 공간에 배치
- AI 사진 인증 **서버에서 성공 응답**을 받은 후에만 별도 장식 아이템 지급 (미션 ID당 한 번)
- 토끼 이동 방향 회전 보정 유지, 천천히 걸어가는 카메라와 지속 생성 지형 유지

## 반드시 알아야 할 제한
- **수집·가방·꾸미기는 localStorage 기반 기기별 데모 데이터입니다.** 다른 기기 또는 다른 브라우저와 동기화되지 않습니다. 기존 사용자 포인트, CO₂, 인증기록은 이 시스템에서 수정하지 않습니다.
- 회원 로그인과 AI 검증은 기존 Firebase 및 `/api/pposong-verify`에 연결하도록 되어 있지만 실제 운영 환경 테스트가 남아 있습니다.
- 기존 상점/결제/모임/관리 기능 전체가 이 파일에 통합된 것은 아닙니다.
- 본 ZIP은 **운영 최종 교체본이 아니라 게임 기능 통합 테스트 후보본**입니다.
- 새로운 게임 아이템 보상은 Firebase에서 지급하지 않아 로컬 저장값 조작이 가능하며 재화/거래 가치가 없습니다.
- 정식 출시 전에 인증 기록 연동 및 게임 아이템 서버 저장, Firebase 규칙 검증, 주문/관리 UI 이전이 필요합니다.

## 조작
행성 클릭 → 착륙 → WASD/방향키 산책 → 반짝이는 수집품에 가까이 접근 → '✨ 줍기'. 🎒 가방에서 재료를 확인하고 🪴 꾸미기에서 소품을 제작·설치합니다.
