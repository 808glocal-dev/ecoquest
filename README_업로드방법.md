# 뽀송별 v5 — 우주 탐험·행성 착륙

## 실행 방식
- `뽀송별_우주체험_v5.html`: 다운로드해서 파일 하나를 브라우저로 열면 실행되는 로그인 없는 체험판.
- `index.html`: 기존 웹사이트의 `index.html`을 바꿀 수 있는 통합 테스트 버전. 기존 Firebase 프로젝트·회원 DB·미션 인증 로직은 유지합니다.
- `service-worker.js`: PWA 캐시 버전을 갱신한 파일입니다.

## 이번 버전의 조작
1. **우주에서 시작**: 7개 행성이 넓게 배치된 우주를 마우스로 끌어 둘러봅니다.
2. **확대·축소**: 마우스 휠, 오른쪽 + / − 버튼, 트랙패드, 모바일 두 손가락 핀치를 사용합니다. 전체 보기로 돌아갈 수 있습니다.
3. **행성 접근**: 행성을 선택하면 카메라가 서서히 가까워집니다. 아직 지상으로 내려가지 않습니다.
4. **착륙**: `🛸 이 별에 착륙하기`를 직접 누른 경우에만 착륙 애니메이션 뒤 지상에서 산책할 수 있습니다.
5. **지상 미션**: 땅 클릭 / 방향키 / 모바일 조이스틱으로 걷고, 미션 표지판에 다가가 선택할 수 있습니다. AI 인증은 원래 앱에 위임합니다.
6. **쉬기**: 앉기, 음악, 동물 친구 만나기는 선택 사항입니다. 아무것도 하지 않아도 됩니다.

## 배포 안전 지침
1. **기존 GitHub 파일을 삭제하지 마세요.** `main`을 백업하고 `pposong-test` 브랜치에서만 우선 테스트합니다.
2. ZIP 압축을 푼 다음 `index.html`과 `service-worker.js`만 저장소 루트의 해당 파일을 교체합니다. 기존 api/·패치 JS·icons/·회원/포인트/인증 데이터는 그대로 둡니다.
3. 테스트 브랜치를 별도의 프리뷰 URL로 배포하는지 확인하세요. `main`에 올리지 않으면 운영 사이트는 변하지 않을 수 있습니다.
4. 기존 계정 로그인 → 우주 첫 화면 → 휠 확대/축소 → 행성 클릭 후 접근 → 착륙 → 미션 표지판 → AI 인증 → 기존 기록 확인 순서로 점검하세요.
5. 실제 Firebase 인증/저장 및 기존 모든 패치 통합 테스트는 아직 완료되지 않았습니다. 운영 반영 전에 꼭 확인해야 합니다.

**주의:** 행성/지구의 회복 그래픽은 게임 내 연출입니다. 기존 CO₂ 데이터는 추정량으로 표기합니다. 별도로 회원 데이터 초기화 코드를 추가하지 않았습니다.
